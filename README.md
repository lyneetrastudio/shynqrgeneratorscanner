# SHYN QR Studio

SHYN QR Studio is a Windows desktop application for creating, customizing, and scanning QR codes. Built with WinUI 3, it combines advanced visual customization, image editing, QR validation, and integrated web browsing in a unified workspace.

## Features

### QR Code Generation

- Customizable QR code colors, backgrounds, dimensions, and padding.
- Transparent backgrounds and rounded canvas designs.
- Custom logo integration with adjustable positioning and center clearance.
- Image cropping, rotation, and aspect ratio adjustment.
- Interactive preview with zoom, pan, and fit controls.
- QR code readability validation.
- Adjustable export resolution.
- PNG and SVG export.
- Direct image copying to the clipboard.

### QR Code Scanner

- Scan QR codes from image files, clipboard images, drag-and-drop, and camera snapshots.
- Interactive image preview with zoom and pan controls.
- Automatic recognition and classification of decoded content.
- Contextual actions based on decoded information.
- Clipboard copying, web search, and direct destination handling.

### Integrated Web Browser

- Chromium-powered browser using Microsoft Edge WebView2.
- Integrated web navigation without leaving the application.
- Back, forward, reload, and stop controls.
- External browser integration.
- Configurable search engine preferences.
- Browser security information.
- Controlled application protocol handoff.

### Windows Application Integration

- Windows application association detection.
- Registered application names and icons where available.
- Application-specific actions for supported destinations.
- Direct launching for selected WhatsApp and Spotify links.
- Application availability verification.
- Web fallback when a compatible application is unavailable.
- Controlled handling of application launch failures.

### User Interface

- Modern Windows desktop interface built with WinUI 3.
- Light and dark theme support.
- Dedicated QR generation and scanning workspaces.
- RGB and HEX color controls.
- Apply, Revert, and Reset controls for appearance adjustments.
- Context-sensitive actions and configuration controls.

### Privacy and Security

- Local QR code generation and decoding.
- No dependency on online QR generation services.
- Restricted browser destination handling.
- Controlled external application requests.
- User confirmation for supported browser-to-application handoffs.
